# Lab 01 – Linux File System Fundamentals

## Objective

Learn the basic Linux file system and essential terminal commands required for cybersecurity and system administration.

---

## Topics Covered

- Directory navigation
- Creating files and folders
- Copying files
- Moving and renaming files
- Deleting files
- Viewing file contents
- Finding files
- Basic text searching

---

## Commands Practiced

```bash
pwd
ls
ls -la
cd
mkdir
touch
cp
mv
rm
cat
echo
find
grep
```

---

## Learning Outcomes

- Understood Linux directory structure.
- Learned how to manage files from the terminal.
- Practiced command-line navigation.
- Built the foundation required for future penetration testing labs.
