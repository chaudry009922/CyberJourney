# Lab 02 – Linux System Monitoring and Process Investigation

## Objective

Understand how Linux manages processes, permissions, log files, and system resources. Develop a Python-based system information dashboard.

---

## Topics Covered

- File permissions
- chmod
- ps
- top
- kill
- journal logs
- /var/log
- Process monitoring
- Python system monitoring

---

## Commands Practiced

```bash
ls -l
chmod
ps
ps aux
top
kill
find /var/log
whoami
uname -a
```

---

## Python Project

Created a Python tool that displays:

- Current user
- Hostname
- CPU usage
- Memory usage
- Disk usage
- IP addresses
- Current working directory
- Operating system information
